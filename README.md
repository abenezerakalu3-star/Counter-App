# React Simple Counter

A simple React application that demonstrates state management using the `useState` hook. The app allows users to increase and decrease a counter value by clicking buttons.

## Features

- Display the current count
- Increase the count
- Decrease the count
- Built with React functional components
- Uses the `useState` hook for state management
